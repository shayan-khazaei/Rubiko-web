<h2>🔧 &nbsp; Rubiko-Web</h2>
Rubiko is a modern web application focused on the Rubik's Cube ecosystem, providing resources, information, and tools for cube enthusiasts.

## 🚀 Live Demo

https://gregarious-cheesecake-fa10cc.netlify.app

<h2>🔧 &nbsp; Features</h2>

- 🧩 Solution Guides

  - Beginner Guides
  - Speedcubing Guides
  - Algorithms

- 📰 News Section

- 📖 Rubik's Cube History

- 🏷️ Cube Brands

- 🎨 Modern User Interface
- User Authentication

- Protected Routes
- Form Validation
- Responsive Design

<h2>🔧 &nbsp; Built With</h2>

- React
- React Router
- Vite
- Tailwind CSS
- JavaScript (ES6+)

<h2>🔧 &nbsp; Upcoming Features</h2>
- Dark mode
